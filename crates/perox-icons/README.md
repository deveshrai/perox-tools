# perox-icons

Every icon in the IDE: [Lucide](https://lucide.dev) 0.460.0 SVGs (ISC, `icons/LICENSE-lucide`),
embedded and tinted to the theme. No emoji anywhere in the UI: use an `Icon`.
To add one, download it from the same Lucide version, replace `currentColor` with
`#ffffff`, put it in `icons/`, and add the variant in `src/lib.rs`.
